# 💳 Kakao Map API 기반 사용자 위치 은행 검색 서비스


## 👥 팀원

* 박성연
* 오세진

## 📌 프로젝트 개요

Kakao Map API를 활용하여 사용자 위치 기반의 은행 검색 페이지를 구현한 웹 프로젝트입니다.
순수 HTML, CSS, JavaScript(바닐라 JS)만 사용하여 지도 출력, 은행 검색, 마커 표시, 경로 안내 기능을 직접 구현하였습니다.

외부 API 문서를 분석하고 실제 서비스 형태로 기능을 구현하는 과정을 통해,
프론트엔드 개발 역량과 API 활용 능력을 향상시키는 것을 목표로 진행하였습니다.

---

## 🎯 프로젝트 목표

* Kakao Map API 활용 능력 향상
* 사용자 위치 기반 서비스(LBS) 구현 경험
* 외부 API 문서 분석 및 적용 능력 강화
* 순수 JavaScript 기반 비동기 처리 및 DOM 제어 학습
* 실제 서비스 형태의 웹 페이지 제작 경험 확보

## ✨ 주요 기능


### 🏦 주변 은행 검색

* Kakao Map API의 장소 검색 기능을 활용하여 주변 은행 정보를 검색합니다.

### 📌 지도 마커 표시

* 검색된 은행 위치를 지도 위 마커로 시각화합니다.

### 🗺 경로 안내

* 선택한 은행까지의 이동 경로를 확인할 수 있습니다.

### 🔍 검색 기반 지도 이동

* 검색 결과 선택 시 해당 위치로 지도를 이동하고 상세 정보를 제공합니다.
